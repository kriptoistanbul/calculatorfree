# Calculator Free

Calculator Free is a multilingual web application offering a large collection of online calculators. It is built with Node.js, Express and EJS templates. The site supports ten languages using the `i18n` module.

## Development

Install dependencies and start the server:

```bash
npm install
npm start
```

Visit `http://localhost:3000` in your browser. Use the language selector to switch between translations.
